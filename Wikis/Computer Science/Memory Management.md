Memory Management in programming languages includes the allocation of [[RAM]] resources. This can include [[Typing]] strength (because different datatypes have different inherent and automatic sizes) and [[Object-Oriented Programming|object]] initialization and deletion, which can either be manual (such as C++) or automatic (most languages). This is called "garbage collection."

Languages that don't have Garbage collection tend to be "lower-level" languages, such as C and [[C++]], Assembly, etc. Most modern languages, such as [[Python]], [[R Programming (fix format)|R]], [[Java]], and even Rust have some form of garbage collection. Garbage collection is the automatic purging of resources when the program detects that the object is not used any more. 

A common issue with programs related to memory management is a [[memory leak]].
