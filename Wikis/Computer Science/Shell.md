A tool that is useful to interface between the [[terminal]] and the operating system. It converts commands into os-level instructions that the computer can execute. In [[linux]], the default is usually [[Bash]] (Bourne Again SHell), and with MacOS the default is [[Zsh]]. The most common remote shell (used to interface with computers without their own interface, such as a [[supercomputer]]) Is called [[SSH]], or Secure SHell.
